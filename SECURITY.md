# Security Policy

## Supported Versions

Security updates are provided for the `master` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Email security reports to `security@hyperstrate.ai` with:

- A description of the issue and affected component
- Reproduction steps or proof of concept
- Any known impact or exploitability notes

We will acknowledge reports as quickly as possible and coordinate a fix before public disclosure.

## Sensitive Data

Do not include API keys, Supabase project secrets, screenshots with private data, or production configuration in bug reports, issues, or pull requests.
